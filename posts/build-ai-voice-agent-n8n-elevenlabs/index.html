Architecture Overview: How Voice Tool-Calling Works

When a caller says, "Can you check the status of order #48291 and email me the receipt?", the request flows through four stages:

  1. ElevenLabs Agent transcribes the speech and detects that the caller's intent matches your custom lookup_order webhook tool.
  2. ElevenLabs sends an authenticated HTTP POST JSON payload containing order_id and session_id to your n8n Webhook URL.
  3. n8n queries your PostgreSQL/Stripe/CRM API, triggers an email or Slack log, and formats a concise 1–2 sentence spoken response.
  4. n8n Respond to Webhook returns clean JSON to ElevenLabs, which speaks the answer naturally back to the caller.

Step 1: Create the n8n Webhook Workflow

Inside n8n (Cloud or self-hosted on Hostinger VPS):

  1. Add a Webhook trigger node:
  • HTTP Method: POST
  • Path: voice-support-lookup
  • Authentication: Header Auth (set a shared secret header like X-Agent-Secret: your-long-random-token so nobody on the public internet can spam your workflow).
  • Respond: Select Using 'Respond to Webhook' Node.
  1. Add your lookup logic (for example, a PostgreSQL query, HTTP Request to Shopify/Stripe, or an AI Agent node querying a vector store).
  2. Add a Respond to Webhook node at the end returning compact, speech-friendly JSON:
{
  "status": "ok",
  "spoken_summary": "Order 48291 shipped via FedEx this morning and is scheduled to arrive tomorrow by 5 PM. I also emailed the tracking link to your address on file.",
  "order_status": "in_transit",
  "eta": "2026-11-25"
}
Voice UX Rule: Never return raw 40-field API JSON objects to a voice agent. Format a clean spoken_summary field inside n8n so the agent speaks naturally without reading UUIDs or timestamps aloud.

Step 2: Register the Webhook Tool in ElevenLabs

Open your ElevenLabs dashboard → Conversational AI → create or edit an Agent:

  1. Under Tools, click Add Tool → Webhook.
  2. Configure the tool contract:
  • Name: lookup_order
  • Description: Looks up live customer order status and triggers a receipt email. Call this whenever the user provides an order number or email.
  • Method: POST
  • URL: Paste your n8n Production Webhook URL (https://n8n.yourdomain.com/webhook/voice-support-lookup).
  • Headers: Add X-Agent-Secret matching your n8n Header Auth credential.
  1. Define the JSON body schema the voice model must extract from speech:
{
  "type": "object",
  "properties": {
    "order_id": {
      "type": "string",
      "description": "Numeric order ID spoken by the caller, stripped of spaces or hashtags"
    },
    "customer_email": {
      "type": "string",
      "description": "Caller email address if mentioned"
    },
    "action": {
      "type": "string",
      "enum": ["check_status", "resend_receipt", "escalate_human"]
    }
  },
  "required": ["action"]
}

Step 3: System Prompt Guardrails for Low Latency

Voice callers hang up if silence lasts longer than 3 seconds. Add these explicit latency and error rules to your ElevenLabs Agent system prompt:

- Keep every spoken reply under 2 short sentences unless the caller asks for details.
- Before invoking `lookup_order`, say a brief filler phrase like "Let me pull up your order right now."
- Never read URLs, JSON keys, or internal error codes aloud.
- If the webhook returns an error or times out, apologize briefly and offer to create a callback ticket.

On the n8n side, set a strict 5-second HTTP timeout on downstream CRM/Stripe nodes and wire an Error Trigger branch so failed tool calls still return {"status": "fallback", "spoken_summary": "I could not reach our order system right now, so I logged a priority callback for our team."} instead of leaving the caller in dead silence.

Frequently Asked Questions

How much does an ElevenLabs AI voice agent cost per minute in 2026?

ElevenLabs offers roughly 15 free conversational agent minutes for testing, paid platform tiers starting around $5–$6/month (Starter) and $22/month (Creator), and high-volume voice agent overages billed around $0.08 per minute plus any external LLM usage.

Can ElevenLabs Conversational AI trigger n8n workflows during a live call?

Yes. By adding a Custom Webhook Tool in ElevenLabs pointing to an n8n POST Webhook node—and returning JSON via n8n's Respond to Webhook node—the voice agent executes backend queries and speaks the live result during the call.

How do I prevent slow webhooks from causing awkward silence in voice calls?

Instruct the voice agent to speak a short filler phrase before calling the tool, keep n8n database queries under 2 seconds, enforce a 5-second timeout with a graceful fallback response, and return a pre-formatted 1–2 sentence spoken_summary.

Should I secure my n8n webhook URL used by ElevenLabs?

Always. Enable Header Auth on the n8n Webhook node (for example, checking a random X-Agent-Secret header) and serve n8n behind HTTPS so unauthorized callers cannot invoke your CRM or database tools.
