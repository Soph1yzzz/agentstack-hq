Python Integration Pattern: Auto-Enrolling App Signups via Webhook

Whether you pick beehiiv's REST API or route events into Systeme.io through a Make webhook bridge, keep your application backend decoupled with a thin async Python client:

import os
import json
import urllib.request
from typing import Any


def enroll_subscriber(
    email: str,
    source: str,
    tags: list[str],
    provider: str = "beehiiv",
) -> dict[str, Any]:
    """Push a new user signup to beehiiv API or a Systeme.io/Make webhook."""
    if provider == "beehiiv":
        pub_id = os.environ["BEEHIIV_PUB_ID"]
        url = f"https://api.beehiiv.com/v2/publications/{pub_id}/subscriptions"
        headers = {
            "Authorization": f"Bearer {os.environ['BEEHIIV_API_KEY']}",
            "Content-Type": "application/json",
        }
        payload = {
            "email": email,
            "utm_source": source,
            "reactivate_existing": False,
            "send_welcome_email": True,
        }
    else:
        # Route to Systeme.io via Make/n8n webhook trigger
        url = os.environ["SYSTEME_WEBHOOK_URL"]
        headers = {"Content-Type": "application/json"}
        payload = {"email": email, "source": source, "tags": tags}

    req = urllib.request.Request(
        url,
        data=json.dumps(payload).encode("utf-8"),
        headers=headers,
        method="POST",
    )
    with urllib.request.urlopen(req, timeout=10) as resp:
        return {"status": resp.status, "provider": provider}

Production tips before shipping this handler:

  1. Never block user signup on third-party email APIs: Enqueue enroll_subscriber() in a background task (FastAPI BackgroundTasks or Redis queue) so a 2-second API hiccup never fails a user registration.
  2. Tag by intent, not just source: Pass the exact lead magnet or guide slug (e.g., tag="docker-blueprint") so your welcome sequence sends relevant follow-ups instead of generic blasts.
  3. Enforce double opt-in or bot filtering: Pair public signup forms with honeypot fields or Turnstile so spambots do not burn your subscriber tier limits.

Who Should Choose What?

  • Choose Systeme.io if you are an indie hacker, developer-creator, or solopreneur who wants landing pages, digital product checkouts, email automations, and an affiliate program in one place starting at $0/month.

Frequently Asked Questions

Is Systeme.io really free forever in 2026?

Yes. Systeme.io offers a permanent $0 Free plan supporting up to 2,000 contacts, unlimited email sends, 3 sales funnels, 1 blog, and basic automation rules—making it one of the lowest-risk ways to launch a creator or indie product funnel.

Does beehiiv's free plan include email automations and webhooks?

No. beehiiv's Free plan supports up to 2,500 subscribers and basic newsletter publishing, while email automations and up to 3 webhooks unlock on the Lite plan ($49–$59/month) and the Send API plus unlimited webhooks unlock on the Pro plan ($95–$109/month).

Which platform is cheaper once you pass 10,000 email subscribers?

Systeme.io is significantly cheaper at scale. Its Webinar plan ($47/month) covers 10,000 contacts and its Unlimited plan caps out at $97/month regardless of list size, whereas beehiiv scales upward with subscriber tiers.

Can I connect a custom Python or static website to Systeme.io or beehiiv?

Yes. beehiiv provides a direct REST API for pushing subscribers from custom frontends, while Systeme.io integrates cleanly with custom apps via Make or n8n webhook triggers and embedded opt-in forms.
